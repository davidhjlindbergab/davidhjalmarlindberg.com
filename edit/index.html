Connect your website

The editor saves your changes straight to the website's files on GitHub. It needs a key that lets it do that. You make the key once, and only this website can be changed with it.

  1. Open GitHub › New fine-grained token (sign in as davidhjlindbergab).
  2. Token name: Site editor. Expiration: 90 days or longer.
  3. Repository access: Only select repositories › davidhjalmarlindberg.com.
  4. Permissions › Repository permissions › Contents: Read and write.
  5. Press Generate token, copy it and paste it here.
The site editor needs a bigger screen. Open it on a computer.
